One-time setup needed

This app syncs mess data through a free Firebase project. Before it will work, open index.html in a text editor and paste your Firebase project's config into the firebaseConfig object near the top of the script.

Full step-by-step instructions (creating the project, enabling Anonymous sign-in, setting up Firestore, and the exact security rules to paste) are in README.md, included alongside this file.

Once the config is filled in, reload this page.
